## Ejecutar en Desarrollo

1. Clonar el repositorio
2. Ejecutar el siguiente comando
```
yarn install
```

3. Tener Nest CLI instalado
```
npm i -g @nestjs/cli
```


4. Clonar ek archivo __.env.template__ y renombrar la copia a __.env__

5. Llenar las variables de entorno definidas en el __.env__

6. Correr el proyecto
```
yarn start:dev
```

7. ejecutar seed
```
http://localhost:3000/seed/cantidad_de_pokemon

```

## Stack usado

* MongoDB
* Nest JS
